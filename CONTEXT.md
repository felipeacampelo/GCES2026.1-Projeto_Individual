# Projeto mk.js Modernizado

Este contexto descreve a linguagem do Projeto acadêmico baseado no `mk.js` e os conceitos usados para planejar sua evolução ao longo das fases de avaliação.

## Language

**Projeto**:
A entrega acadêmica completa que moderniza a Aplicação Base e implementa os critérios de avaliação definidos no `README`.
_Avoid_: Trabalho, sistema, jogo

**Aplicação Base**:
O software herdado `mk.js` usado como ponto de partida técnico para o Projeto.
_Avoid_: Projeto, produto final

**Fase**:
Cada etapa avaliativa do Projeto, com objetivo, artefatos e evidências próprios.
_Avoid_: Tarefa, sprint, milestone

**Fundação Transversal**:
A etapa inicial que saneia compatibilidade, dependências e documentação-base para destravar as fases seguintes do Projeto.
_Avoid_: Fase zero, correção inicial
